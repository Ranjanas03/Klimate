# 🌦️ Klimate Weather App

A modern weather forecasting application built with **React**, **TypeScript**, and **Vite**. It fetches real-time weather data using the **OpenWeatherMap API** and displays it in a clean, responsive UI.

## 🚀 Live Demo

👉https://klimateandweather.netlify.app/

---

## ✨ Features

- 🌍 Get weather data for your current location
- 🔍 Reverse geocoding to detect city names from coordinates
- 🌡️ Temperature, humidity, wind speed, and more
- ⚡ Fast and lightweight (Vite-powered)
- 📱 Responsive and mobile-friendly design
- 🛠️ Built with React + TypeScript

---

## 📦 Tech Stack

- React
- Vite
- TypeScript
- OpenWeatherMap API
- Tailwind CSS

## 🛠️ Installation & Setup

# 1. Clone the repo
git clone 
cd klimate

# 2. Install dependencies
npm install

# 3. Add your OpenWeatherMap API key to a .env file

# 4. Start the development server
npm run dev
